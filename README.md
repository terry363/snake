# 蛇之圖鑑 Snake Atlas

純 HTML / CSS / JavaScript 靜態網站。

## 使用方式

直接開啟 `index.html` 即可瀏覽；若瀏覽器限制本機跨檔案功能，可使用任何靜態伺服器啟動。

## 專案結構

- `index.html`：首頁與圖鑑框架
- `styles.css`：網站樣式
- `script.js`：蛇類資料、搜尋、篩選、Dialog 互動
- `design.md`：視覺設計規範
- `entries/`：每個條目的 HTML 作品
- `assets/slides/`：簡報範例
- `assets/images/`：本機圖片預留目錄

## 擴充

新增蛇種時，修改 `script.js` 裡的 `snakes` 陣列即可。
