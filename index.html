WHY THIS ATLAS

一個適合持續成長的內容框架

01

模組化內容

每個條目由一致的資料結構驅動，新增品種時不必重做版面。

02

多媒體支援

可加入圖像、文字、嵌入式 HTML 作品，也可連結或嵌入簡報。

03

響應式設計

卡片、導覽與內容視窗會依螢幕寬度調整，手機與桌機皆適用。

EXTENSIBLE

新增一個條目，只需加入一筆資料

網站資料集中在 script.js 的 snakes 陣列。複製一筆物件並修改名稱、圖片、介紹與媒體欄位，即可新增更多蛇種。

{
  name: "新蛇種",
  scientific: "Scientific name",
  habitat: "forest",
  image: "assets/images/example.jpg",
  description: "條目介紹",
  htmlWork: "entries/example.html",
  slides: "assets/slides/example.pdf"
}
